# 🌉 조달청 나라장터 교량/공사 입찰공고 자동 알림 & 웹 대시보드

공공데이터포털의 **'조달청 나라장터 입찰공고 정보 API'**를 활용하여 **기술용역** 및 **공사** 분야 중 **교량 / 다리 / OO교** 관련 1억 원 이상 신규 공고를 매일 아침 **텔레그램**, **이메일**로 받아보고 **무료 웹 대시보드**에서 조회하는 자동화 시스템입니다.

## ❓ 왜 노션 대신 '웹 대시보드'인가요?

1. **회원가입/앱 설치 불필요**: 노션 계정이나 앱이 없어도 스마트폰이나 PC의 웹 브라우저(크롬, 파이어폭스, 에지 등)로 주소(URL)만 클릭하면 바로 연결됩니다.
2. **100% 평생 무료**: GitHub Pages 서비스를 이용하여 별도 서버 비용 없이 평생 무료로 웹 사이트가 유지됩니다.
3. **편리한 검색 & 정렬**:
   * **실시간 검색창**: 공고명, 수요기관명, 공고번호 입력 시 즉시 필터링
   * **금액순/최신순 정렬**: 추정가격 높은 순 / 낮은 순 / 최신 게시일 순 정렬
   * **분야별 보기**: 기술용역 / 공사 선택 필터링
   * **바로가기 버튼**: 클릭 한 번으로 나라장터 공식 상세 페이지로 이동

## 🌐 GitHub Pages 웹 대시보드 활성화 방법 (최초 1회)

1. GitHub 저장소 ➔ **Settings** 탭 클릭
2. 좌측 메뉴에서 **Pages** 클릭
3. **Source** 항목을 `GitHub Actions`로 변경
4. 설정 완료 후, 매일 아침 08:30분마다 `https://<본인아이디>.github.io/<저장소이름>/` 주소로 웹 대시보드가 자동 업그레이드됩니다.
